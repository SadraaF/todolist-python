# ToDo List - Python (Phase 3 - Web API)

This project is a ToDo list application built in Python, showcasing a layered architecture, data persistence with PostgreSQL, and a RESTful API built with FastAPI. It has evolved from a simple in-memory tool to a full-featured web service.

This third phase deprecates the command-line interface in favor of a modern, documented Web API, making the application's logic accessible over the network and ready for integration with front-end clients.

## Key Features

-   **Web API:** A comprehensive RESTful API built with **FastAPI**.
-   **Automatic Interactive Documentation:** API documentation is auto-generated by FastAPI and available via Swagger UI (`/docs`) and ReDoc (`/redoc`).
-   **Data Persistence:** Data is stored in a **PostgreSQL** database, managed with Docker.
-   **ORM Integration:** Uses **SQLAlchemy** as the Object-Relational Mapper.
-   **Database Migrations:** Employs **Alembic** to manage and version the database schema.
-   **Layered Architecture:** The code is cleanly separated into layers: Controllers (API), Services (Business Logic), and Repositories (Data Access).
-   **Dependency Injection:** FastAPI's DI system is used to manage dependencies and ensure clean, testable code.

## Technologies Used

-   **Language:** Python 3.12+
-   **API Framework:** FastAPI
-   **Web Server:** Uvicorn
-   **Dependency Management:** Poetry
-   **Database:** PostgreSQL
-   **Containerization:** Docker
-   **ORM:** SQLAlchemy
-   **Migration Tool:** Alembic
-   **Data Validation:** Pydantic

## How to Run

### Prerequisites

-   [Poetry](https://python-poetry.org/) installed on your system.
-   [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed and running.

### 1. Initial Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/SadraaF/todolist-python.git
    cd todolist-python
    ```

2.  **Install dependencies:**
    Poetry will create a virtual environment and install all required packages.
    ```bash
    poetry install
    ```

3.  **Configure Environment:**
    Create a `.env` file from the example. The default values are configured to work with the provided Docker setup.
    ```bash
    cp .env.example .env
    ```

4.  **Start the Database:**
    This command will start the PostgreSQL database container in the background.
    ```bash
    docker-compose up -d
    ```

5.  **Apply Database Migrations:**
    This command will create the necessary tables (`projects`, `tasks`) in the database.
    ```bash
    poetry run alembic upgrade head
    ```

### 2. Running the API Server

With the setup complete, you can now run the web server.

```bash
poetry run uvicorn main:app --reload
```

The API will be available at `http://127.0.0.1:8000`.

### 3. Accessing the API

-   **Interactive Documentation (Swagger UI):** Open your browser and navigate to [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs). Here you can view all available endpoints and test them directly.
-   **Alternative Documentation (ReDoc):** Navigate to [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc).

#### Testing with Postman

A complete Postman collection can be created to test all available endpoints. It is recommended to set up an environment with a `base_url` variable set to `http://127.0.0.1:8000/api/v1` for efficient testing.

### 4. Running the (Deprecated) CLI

The Command-Line Interface is still available but is deprecated and will be removed in a future version. To run it:

```bash
poetry run python run_cli.py
```

## Project Architecture

The codebase is organized into a modular, layered structure:

-   `main.py`: The entry point for the FastAPI application.
-   `run_cli.py`: The entry point for the deprecated CLI.
-   `src/app/api/`: Contains the API layer, including controllers, schemas, and dependencies.
-   `src/app/core/`: Core application logic, like configuration management.
-   `src/app/services/`: The business logic layer.
-   `src/app/repositories/`: The data access layer.
-   `src/app/models/`: SQLAlchemy ORM models.
-   `src/app/db/`: Database session and engine configuration.
-   `alembic/`: Database migration scripts.
